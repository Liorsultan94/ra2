# שלט AI ל-PS5

אומרים או כותבים בטלפון מה רוצים ("תדליק את הפלייסטיישן ותכניס אותי ל-FIFA"), ו-Claude מדליק את הקונסולה, מנווט בתפריטים ופותח את המשחק.

```
טלפון (דפדפן)  →  שרת קטן בבית (המחשב שלך / Raspberry Pi)  →  Claude מחליט מה לעשות
                                    ↓
                    pyremoteplay (Remote Play) → PS5
```

## מה זה יודע לעשות

- להדליק את ה-PS5 ממצב מנוחה ולכבות אותו
- לבדוק מה רץ עכשיו
- ללחוץ על כל כפתור של השלט (✕ ○ △ □, חצים, PS, Options, L1/R1...)
- **לראות את המסך** (צילום מסך דרך Remote Play), וכך לנווט בעצמו לכל משחק או אפליקציה
- קיצורים שמורים: רצף כפתורים קבוע שמוגדר לכל משחק
- שלט ידני בדף, בלי AI

## דרישות

- מחשב (Windows / Mac / Linux) או Raspberry Pi 4/5 **באותה רשת ביתית** של ה-PS5, עם Python 3.10 ומעלה
- מפתח API של Anthropic: <https://console.anthropic.com>
- ב-PS5: **הגדרות ← מערכת ← Remote Play ← להפעיל את Remote Play**
- ב-PS5: **הגדרות ← מערכת ← חיסכון בחשמל ← תכונות זמינות במצב מנוחה ← להשאיר מחובר לאינטרנט + לאפשר הדלקה מהרשת**

## התקנה

```bash
cd ps5-ai-remote
python -m venv venv
source venv/bin/activate          # ב-Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 1. חיבור ל-PS5 (פעם אחת)

```bash
python -m pyremoteplay <כתובת-IP-של-ה-PS5> --register
```

1. התהליך יבקש להתחבר לחשבון PSN בדפדפן ולהדביק בחזרה את הכתובת שמתקבלת אחרי ההתחברות.
2. ב-PS5: **הגדרות ← מערכת ← Remote Play ← קישור מכשיר**. יופיע קוד בן 8 ספרות. מקלידים אותו בטרמינל.

את כתובת ה-IP של ה-PS5 מוצאים ב: **הגדרות ← רשת ← מצב חיבור**.

### 2. הגדרות

```bash
cp config.example.yaml config.yaml
```

ממלאים ב-`config.yaml` את `ps5_host` (ה-IP) ואת `psn_user` (שם המשתמש שנרשם בשלב 1).

### 3. הפעלה

```bash
export ANTHROPIC_API_KEY=sk-ant-...      # ב-Windows: set ANTHROPIC_API_KEY=sk-ant-...
python server.py
```

בטלפון פותחים `http://<כתובת-IP-של-המחשב>:8000`. כדאי להוסיף את הדף למסך הבית.

## דיבור

- **הכי פשוט:** לוחצים על המיקרופון **במקלדת של הטלפון** ומכתיבים.
- **כפתור 🎤 בדף:** הדפדפן מאפשר מיקרופון רק ב-HTTPS. אפשר ליצור תעודה ולהריץ:
  ```bash
  openssl req -x509 -newkey rsa:2048 -nodes -days 3650 -keyout key.pem -out cert.pem -subj "/CN=ps5"
  python server.py --cert cert.pem --key key.pem
  ```
  אחר כך פותחים `https://...:8000` ומאשרים את האזהרה על התעודה.

## עלות ומהירות

כל בקשה היא כמה קריאות ל-Claude. צילום מסך מוסיף זמן ועלות, אבל בלעדיו ה-AI מנווט "בעיניים עצומות". כדי לחסוך אפשר לכבות את `screenshots` ולהגדיר `shortcuts` למשחקים הקבועים. ההגדרות האלה נמצאות ב-`agent.py` (`MODEL`, `effort`).

## אבטחה

- השרת פתוח לכל מי שמחובר לרשת הביתית. כדאי להגדיר `access_token` ב-`config.yaml`.
- **לא** לחשוף את הפורט לאינטרנט. לשליטה מחוץ לבית עדיף VPN כמו Tailscale.
- ה-AI מונחה לא לבצע רכישות, לא למחוק ולא לשנות הגדרות מערכת.

## מגבלות ידועות

- PS5 לא מאפשר "פתיחת משחק לפי שם" דרך הרשת, ולכן הניווט נעשה בלחיצות כפתורים כמו אדם עם שלט.
- בזמן שה-AI מחובר ב-Remote Play, הקונסולה מציגה שמשתמש Remote Play מחובר.
- `pyremoteplay` היא ספריית קוד פתוח לא רשמית. עדכון מערכת של Sony עלול לשבור אותה.
