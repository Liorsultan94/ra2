# שלט AI ל-PS5

אומרים או כותבים בגלקסי מה רוצים, למשל "תדליק את הפלייסטיישן ותכניס אותי ל-MyTeam", ו-Claude מדליק את הקונסולה, מנווט בתפריטים ופותח את המשחק. זה עובד מהבית וגם מבחוץ.

```
גלקסי (בבית או בחוץ) ──Tailscale──▶ מחשב ישן בבית ──Remote Play──▶ PS5
                                         │
                                         └──▶ Claude (מחליט מה ללחוץ, רואה את המסך)
```

## מה זה יודע לעשות

- להדליק את ה-PS5 ולכבות אותו
- לבדוק מה רץ עכשיו
- **לראות את המסך** ולנווט לבד למשחק או לאפליקציה
- **NBA 2K24 MyTeam:** להיכנס, להגיע לחנות או לשוק ולהגיד לך מה יש ומה המחירים
- **קנייה ומכירה רק באישור שלך:** ה-AI מציע פעולה עם צילום מסך, ושום דבר לא נלחץ עד שאתה לוחץ "אשר" בטלפון
- שלט ידני בדף, בלי AI

> ⚠️ **אין קנייה או מכירה אוטומטית.** בוט שסוחר לבד ב-MyTeam מפר את תנאי השימוש של 2K ועלול לגרום לחסימת החשבון. לכן ה-AI מציע פעולה אחת בכל פעם ומחכה לאישור. גם שליטה ממוחשבת עם אישור היא שימוש לא רשמי, והאחריות היא שלך.

## התקנה, צעד אחר צעד

### שלב 1: הגדרות ב-PS5 (פעם אחת)

1. **הגדרות ← מערכת ← Remote Play** ← להפעיל את **Enable Remote Play**.
2. **הגדרות ← מערכת ← חיסכון בחשמל ← תכונות זמינות במצב מנוחה** ← להפעיל את **Stay Connected to the Internet** ואת **Enable Turning On PS5 from Network**.
3. כדאי לקבוע ל-PS5 כתובת IP קבועה בראוטר (DHCP Reservation), כדי שהכתובת לא תשתנה.
   את הכתובת הנוכחית רואים ב: **הגדרות ← רשת ← מצב חיבור ← View Connection Status**.

### שלב 2: התקנה על המחשב הישן (Windows 10/11)

1. מתקינים **Python 3.12** מ-<https://www.python.org/downloads/>.
   ⚠️ במסך הראשון של ההתקנה מסמנים **"Add python.exe to PATH"**.
2. מורידים את התיקייה `ps5-ai-remote` למחשב (למשל ל-`C:\ps5-ai-remote`).
3. לוחצים פעמיים על `windows\install.bat` ומחכים שיסיים.

### שלב 3: חיבור המחשב ל-PS5 (פעם אחת)

1. לוחצים פעמיים על `windows\register.bat` ומקלידים את ה-IP של ה-PS5.
2. נפתח קישור להתחברות לחשבון PSN. מתחברים, ובסוף מעתיקים את **כל הכתובת** משורת הכתובת של הדפדפן ומדביקים בחלון השחור.
3. ב-PS5: **הגדרות ← מערכת ← Remote Play ← Link Device**. יופיע קוד בן 8 ספרות. מקלידים אותו בחלון השחור.
4. נפתח `config.yaml`. ממלאים בו את `ps5_host` (ה-IP) ואת `psn_user` (שם המשתמש שהופיע בשלב 2), ושומרים.

### שלב 4: מפתח ה-API של Claude

יוצרים בתיקייה `ps5-ai-remote` קובץ בשם `anthropic_key.txt`, ובתוכו רק המפתח (`sk-ant-...`).
הקובץ לא נשמר ב-git.

### שלב 5: הפעלה

- לוחצים פעמיים על `windows\start.bat`. החלון צריך להישאר פתוח, ואפשר למזער אותו.
- כדי שהשלט יופעל לבד בכל הדלקה של המחשב: לוחצים פעמיים על `windows\autostart.bat`.
- **חשוב:** ב-Windows ← **הגדרות ← מערכת ← הפעלה ושינה ← שינה: אף פעם**. אחרת המחשב יירדם והשלט יפסיק לעבוד.
- בפעם הראשונה Windows ישאל על חומת האש. מאשרים **רשתות פרטיות**.

בדיקה ראשונה מהבית: בגלקסי, כשהוא מחובר ל-Wi-Fi הביתי, פותחים `http://<IP-של-המחשב>:8000`.
את ה-IP של המחשב רואים בחלון השחור עם הפקודה `ipconfig`, בשורה IPv4 Address.

### שלב 6: שליטה מחוץ לבית עם Tailscale (חינמי)

1. מתקינים **Tailscale** על המחשב הישן (<https://tailscale.com/download>) ומתחברים עם חשבון Google.
2. מתקינים **Tailscale** מחנות Google Play על הגלקסי ומתחברים **עם אותו חשבון**.
3. מפעילים HTTPS (צריך את זה גם בשביל המיקרופון):
   - באתר הניהול <https://login.tailscale.com/admin/dns>: מפעילים **MagicDNS** ו-**HTTPS Certificates**.
   - במחשב הישן פותחים את שורת הפקודה (cmd) ומריצים:
     ```
     tailscale serve --bg 8000
     ```
   - הפקודה תדפיס כתובת כמו `https://my-pc.tail1234.ts.net`. זו הכתובת של השלט.
4. בגלקסי פותחים את הכתובת ב-Chrome ← תפריט ⋮ ← **הוספה למסך הבית**. מעכשיו זה נראה כמו אפליקציה.

כשהאפליקציה של Tailscale מחוברת בגלקסי, השלט עובד מכל מקום, גם ב-4G/5G. אין צורך לפתוח פורטים בראוטר.

- "תדליק את הפלייסטיישן"
- "תכניס אותי ל-NBA 2K24 ל-MyTeam"
- "מה יש בחנות של MyTeam ומה המחירים?"
- "תחפש לי בשוק את לברון ותגיד כמה הוא עולה"
- "תציע לי לקנות אותו ב-5000" ← מופיע כרטיס עם **אשר / דחה**
- "תחזור למסך הבית" / "תכבה את הסוני"

## קיצורים שמורים (חוסכים זמן וכסף)

אם יש משחק שתמיד נמצא באותו מקום במסך הבית, אפשר לשמור את רצף הכפתורים ב-`config.yaml`:

```yaml
shortcuts:
  2k24: [PS, PS, LEFT, LEFT, LEFT, LEFT, LEFT, RIGHT, CROSS]
```

ה-AI ישתמש בקיצור במקום לצלם ולחפש.

## עלות

כל בקשה היא כמה קריאות ל-Claude. צילומי מסך מייקרים את הבקשה. ניווט ארוך, כמו כניסה ל-2K24 ולחנות, יכול להגיע לכמה עשרות סנטים. את מעקב החיוב ותקרת ההוצאה מגדירים ב-<https://console.anthropic.com>.

## אבטחה

- דרך Tailscale רק המכשירים שלך מגיעים לשלט. בכל זאת כדאי להגדיר `access_token` ב-`config.yaml`.
- **לא** לפתוח את פורט 8000 בראוטר לאינטרנט.

## מגבלות ידועות

- ה-PS5 לא מאפשר לפתוח משחק לפי שם דרך הרשת, אז ה-AI מנווט בלחיצות כמו אדם עם שלט. כניסה ל-2K24 לוקחת כדקה עד שתיים, בגלל זמני הטעינה של המשחק.
- בזמן שהשלט מחובר, ה-PS5 מציג שמשתמש Remote Play מחובר. מי שמשחק עם שלט רגיל יכול להמשיך כרגיל.
- `pyremoteplay` היא ספריית קוד פתוח לא רשמית. עדכון מערכת של Sony עלול לשבור אותה זמנית.
- הכללים על קניות נאכפים דרך ההנחיות ל-AI ודרך כרטיס האישור. אבל ל-AI יש גישה לכל הכפתורים, אז כדאי להגדיר תקרת הוצאה גם בחשבון ה-PSN.

## Linux / Raspberry Pi

```bash
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt && pip install --no-deps pyremoteplay==0.7.6
python -m pyremoteplay <PS5-IP> --register
cp config.example.yaml config.yaml   # ממלאים
ANTHROPIC_API_KEY=sk-ant-... python server.py
```
