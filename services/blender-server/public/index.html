REST API Reference & cURL Integration

You can trigger Blender 5.2.2 LTS directly from any backend, frontend, build step, or Python/Node script using standard HTTP calls.

1. Health Check (Blender 5.2.2 Lock)

curl http://localhost:4000/api/health

2. Generate Procedural 3D Model (.GLB)

curl -X POST http://localhost:4000/api/model/generate \
  -H "Content-Type: application/json" \
  -d '{"type": "tank", "faction": "soviet", "color": "#d32f2f"}'

3. Convert & Decimate 3D Model

curl -X POST http://localhost:4000/api/model/convert \
  -F "file=@my_mesh.obj" \
  -F "decimate=0.5" \
  -F "center=true"

4. Background Studio Render (Eevee / Cycles)

curl -X POST http://localhost:4000/api/render/image \
  -H "Content-Type: application/json" \
  -d '{"modelUrl": "/output/models/soviet_tank.glb", "engine": "BLENDER_EEVEE", "angle": "isometric", "width": 800, "height": 800}'

5. 360 Turntable Animation

curl -X POST http://localhost:4000/api/render/turntable \
  -H "Content-Type: application/json" \
  -d '{"modelUrl": "/output/models/soviet_tank.glb", "frames": 16, "engine": "BLENDER_EEVEE"}'
