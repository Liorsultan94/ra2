# Iron Front

A browser real-time strategy game inspired by Red Alert 2, written in TypeScript with Three.js. It runs in any modern browser, phone included, with nothing to install.

**Play:** https://liorsultan94.github.io/ra2/

The game lives in [`web/`](web/); see [web/README.md](web/README.md) for how to run, test and build it.

- `web/` - the game (TypeScript, Three.js, Vite, Vitest)
- `scripts/` - helper scripts (cameo image generation)
- `services/blender-server/` - a local Blender 5.2 server for generating, converting and rendering 3D models

The repository started as a fork of the OpenRA Red Alert 2 mod. All of that old C# mod code has been removed; the game here shares no code with it.
